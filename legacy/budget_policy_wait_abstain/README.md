# Legacy baseline

This directory preserves an earlier budget, policy, and wait/abstain research line. It is retained for auditability but does not participate in the primary evidence chain under `reproducibility/paper_v4/`.

Files were moved without deleting their history. The migration manifest records both the files moved here and keyword-matched files retained in the main tree because they are dependencies of active implementations or tests.

Pytest excludes this directory during the repository's default test run. The archived tests remain available for targeted historical inspection, but their former import paths are not maintained as part of the current package contract.
