# Extended analyses

This index separates exploratory and sensitivity analyses from the primary evidence chain in `reproducibility/paper_v4/`. The underlying files remain in their published package locations so their histories, paths, and checksums are not rewritten.

The following materials are retained as extended analyses and are not used as primary evidence:

- Temporal flip index and prediction-switch counts: `../paper_v2/derived_summaries/boxcar_w3/summary.json` and the associated instance-level bootstrap tables.
- Smoothing coefficient 0.25: `../paper_v1/derived_summaries/G1/bootstrap_deltas.csv` and `../paper_v1/derived_summaries/G4/bootstrap_deltas.csv`.
- Multi-bin calibration scans: `../paper_v1/derived_summaries/G2/ece_bin_sensitivity.csv` and `../paper_v1/derived_summaries/G3/bin_sensitivity.csv`.
- Transition horizons 8 and 32: `../paper_v1/derived_summaries/G2/horizon_sensitivity.csv`.
- Leave-one-video-out checks: `../paper_v1/derived_summaries/G1/leave_one_video_out_deltas.csv` and `../paper_v1/derived_summaries/G4/leave_one_video_out_deltas.csv`.
- All-transition analyses: `../paper_v1/derived_summaries/G2/transition_type_summary.csv`.

This classification changes only the evidence-chain status. No underlying measurement, bootstrap output, provenance record, or audit record is removed or altered.
